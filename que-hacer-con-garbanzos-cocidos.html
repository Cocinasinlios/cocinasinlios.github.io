Hazlos cremosos o frescos.

Hummus si quieres una base que luego sirva para más cosas; ensalada si prefieres textura y frescor.

02 · 20 MIN

Úsalos como estructura.

Cuscús, verdura y garbanzos forman una cena completa sin necesidad de una cocción larga.

03 · 30 MIN

Dales salsa y especias.

Un curry transforma completamente el ingrediente y además aguanta bien de un día para otro.

Qué hacer según cómo quieras comerlos

No busques “otra receta con garbanzos”. Cambia el formato.

Para untar o acompañar: hummus. Para algo frío: ensalada mediterránea. Para una cena rápida: cuscús con verduras. Para algo más de cuchara: curry. Si vienen de bote, escúrrelos y sigue el etiquetado del producto para conservación una vez abierto.
