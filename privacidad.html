Privacidad

Qué ocurre con tus datos.

La web está diseñada para recoger lo mínimo posible.

Navegación.

No utilizamos actualmente analítica de terceros, publicidad comportamental ni píxeles publicitarios. La web mantiene únicamente contadores agregados de uso en el almacenamiento local de este dispositivo —por ejemplo, cuántas veces se abre una herramienta o se pulsa una función— para comprobar que el producto funciona. No se guarda un historial cronológico de navegación, no se crea un identificador de usuario y esos contadores no se envían actualmente fuera del navegador.

Almacenamiento en tu navegador.

Algunas herramientas guardan localmente su estado —por ejemplo la despensa, una semana, la compra, favoritos, recetas recientes o ingredientes que quieres gastar pronto— para que puedas continuar donde lo dejaste. También se guardan los contadores agregados de uso descritos arriba. Todo ello puede borrarse desde “Borrar mis datos de Mi cocina” o desde las opciones de datos del sitio del navegador.

Cuando decides escribirme.

Si pulsas un enlace de contacto, sales de esta web y utilizas un servicio externo como WhatsApp. El mensaje no se envía automáticamente: eres tú quien decide abrir ese servicio y enviarlo. El contacto de esta web está limitado a cuestiones editoriales de Cocina sin líos.

Servicios externos.

El alojamiento del sitio y los servicios externos enlazados pueden tratar datos técnicos conforme a sus propias condiciones. Esta política se actualizará antes de incorporar formularios propios, newsletters, analítica o publicidad que requieran información o consentimiento adicional.

Importante.

Esta página describe el funcionamiento técnico actual de un proyecto editorial no comercial. Si en el futuro se incorporan formularios propios, newsletters, publicidad o servicios económicos, la información legal y de privacidad se actualizará antes de activarlos.
