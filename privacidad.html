Privacidad.

La web está diseñada para recoger lo mínimo necesario y explicar de forma clara qué ocurre con la información que utilizas.

Responsable

Responsable: Macarena Martínez Martín. Correo de contacto y ejercicio de derechos: hola@cocinasinlios.com. El domicilio profesional del responsable está pendiente de actualización en el aviso legal.

Datos guardados en tu navegador

La despensa, el plan semanal, la lista de compra, los favoritos, los ingredientes que quieres gastar pronto, las preferencias que decides evitar y un historial breve de recetas vistas recientemente pueden guardarse en el almacenamiento local de tu navegador. Se utilizan para que las herramientas recuerden tu estado en ese dispositivo. Puedes eliminarlos desde “Borrar mis datos de Mi cocina” o desde las opciones del navegador.

Medición de uso y rendimiento

La web utiliza Cloudflare Web Analytics para obtener estadísticas agregadas de visitas y rendimiento. Según la documentación del proveedor, Web Analytics está diseñado para funcionar sin utilizar cookies ni localStorage para esas métricas y sin crear perfiles individuales de navegación.

Cuando decides contactar

Si escribes a hola@cocinasinlios.com, se tratarán tu dirección de correo, el contenido de tu mensaje y los datos que voluntariamente incluyas para poder responderte. El correo entrante se enruta técnicamente mediante Cloudflare Email Routing y puede gestionarse con proveedores de correo y envío como Google y Brevo. Si utilizas WhatsApp, sales de esta web y el tratamiento pasa también a depender del servicio de Meta/WhatsApp que tú decides utilizar.

Finalidad y conservación

Los datos de contacto se utilizan únicamente para atender la consulta o comunicación que hayas iniciado y se conservarán durante el tiempo necesario para gestionarla y, cuando proceda, durante los plazos necesarios para atender obligaciones o responsabilidades legales. No se utilizan para crear perfiles publicitarios ni se venden a terceros.

Proveedores técnicos

La web utiliza infraestructura y servicios técnicos de terceros, entre ellos GitHub, Cloudflare, Google y Brevo, en la medida necesaria para alojar, servir, medir técnicamente o gestionar comunicaciones relacionadas con el sitio. Cada proveedor puede tratar datos técnicos conforme a sus propias condiciones y garantías aplicables.

Tus derechos

Puedes solicitar acceso, rectificación, supresión, oposición, limitación o, cuando corresponda, portabilidad de tus datos escribiendo a hola@cocinasinlios.com. También puedes presentar una reclamación ante la Agencia Española de Protección de Datos si consideras que el tratamiento no se ajusta a la normativa.
