Transparencia editorial

Qué tiene que cumplir una receta para quedarse aquí.

Cocina sin líos no intenta publicar todo. Intenta publicar cosas que resuelvan una situación doméstica real, expliquen la señal importante y sigan siendo útiles cuando falta un ingrediente o sobra comida.

Si una cifra, una técnica o una afirmación de seguridad importa para que la receta sea fiable, prefiero comprobarla o apoyarla en una fuente adecuada antes que rellenar el hueco con seguridad aparente.

01 · UTILIDAD

Resuelve algo real.

Poco tiempo, una nevera a medias, una sobra, una semana que organizar o una base que conviene hacer de más.

02 · CLARIDAD

Dice qué mirar.

Temperatura, textura, dorado, tiempo orientativo o señal de cocción: lo que permite cocinar mirando el plato y no solo el reloj.

03 · CANTIDADES

Parte de una referencia concreta.

Las fichas tienen raciones base y cantidades que se pueden escalar, con avisos cuando duplicar ingredientes no significa duplicar tiempos.

04 · ADAPTACIÓN

Admite una casa normal.

Incluye sustituciones cuando tienen sentido y evita convertir un ingrediente secundario en una obligación de compra.

05 · APROVECHAMIENTO

Piensa en mañana.

Cuando una preparación puede convertirse en otra comida, la ficha intenta decirlo y enlazar el siguiente uso.

06 · SEGURIDAD

No improvisa lo delicado.

Alérgenos, conservación, recalentado y temperaturas de seguridad se tratan con prudencia y, cuando procede, se contrastan con fuentes oficiales.

Cómo se revisa el contenido

La receta no termina cuando se escribe.

Una ficha útil tiene que mantener coherencia entre lo que promete, las cantidades, el paso a paso, la foto, la categoría, las conexiones de aprovechamiento y los datos estructurados que leen los buscadores.

Primero: intención.

Definir qué problema resuelve y para quién: rapidez, despensa, aprovechamiento, horno, legumbre, cena ligera o cocina con calma.

Después: ejecución.

Revisar ingredientes, raciones, pasos, calor, tiempos y la señal que indica que el alimento está en su punto.

Luego: contexto.

Añadir sustituciones, ideas para sobras y conexiones con otras recetas cuando realmente ayudan.

Por último: coherencia digital.

Comprobar título, canonical, imagen, marcado Recipe, enlaces, accesibilidad y que la página siga funcionando después de cada despliegue.

Cuando la seguridad importa

Las fuentes primarias pesan más que una costumbre de cocina.

Para conservación, recalentado o seguridad alimentaria se priorizan organismos públicos y documentación técnica. En España, una referencia habitual es la Agencia Española de Seguridad Alimentaria y Nutrición (AESAN). Una receta doméstica no sustituye las indicaciones del etiquetado ni las recomendaciones sanitarias aplicables a cada persona.

Lo que no voy a hacer

También hay límites editoriales.

  • No presentar como comprobado algo que no esté suficientemente validado.
  • No inventar testimonios, cifras de uso, valoraciones ni autoridad.
  • No llenar una página de texto solo para hacerla más larga para buscadores.
  • No ocultar una limitación importante detrás de un tono seguro.
  • No mantener una receta si deja de cumplir el estándar del sitio.
